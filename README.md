# Data Analysis Foundations and Storytelling with Data

## Descripción
Este repositorio contiene el desarrollo del proyecto del curso **Data Analysis Foundations and Storytelling with Data**.

El proyecto incluye:
- Análisis de datos | Selección de Indicadores
- Preparación de Business Case
- Elaboración de Dashboad
- Reporte con Storytelling basado en datos

## Contenido
- Archivos Excel

## Objetivo
Analizar y optimizar el porcentaje de kilogramos exportables por campaña en una empresa agroexportadora de arándanos, mediante el uso de análisis de datos, selección de indicadores, dashboards y storytelling, con el fin de incrementar en 10% el KPI de exportabilidad y mejorar la rentabilidad del negocio.
